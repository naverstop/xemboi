## 4. 바이럴 전략 (질문 ①에 대한 답)

바이럴은 "공유할 이유 × 공유가 쉬운 형태 × 공유받은 사람의 진입 동선" 3박자다. Top5의 검증된 수법 + 우리만의 무기를 결합한 8가지:

| # | 방법 | 벤치마크 근거 | 우리 구현 방식 | 기대 효과 |
|---|---|---|---|---|
| V1 | **결과 공유 카드 이미지** | 포스텔러 이용자 35%가 결과를 SNS 공유 | 모든 답변에 "공유 카드" 버튼 — 12띠 캐릭터+오행 차트+핵심 한 줄을 PIL로 이미지 합성(서비스 로고·QR 워터마크). 인스타 스토리 규격(9:16) | 결과 1건 = 광고 1장 |
| V2 | **궁합 상대 초대 링크** | 포스텔러 '초대' 방식 | 초대 URL → 상대방이 자기 생일만 입력 → 양측에 결과. 초대받은 사람 = 신규 가입 동선 | 관계 기반 1:1 확산 (전환율 최고 유형) |
| V3 | **무료 스낵 테스트 + 유형화** | 헬로우봇 '시로' 테스트 수 시간 내 20만 공유, 청월당 무료 44종 | 사주 기반 유형 테스트 2~3종("내 도화살 등급", "올해 재물 기질") — 결과를 유형 카드(V1 규격)로. 무료·비로그인 허용 | 저비용 대량 유입 훅 |
| V4 | **쇼츠 영상 = 우리만의 무기** | 5사 중 영상 산출물 보유 서비스 없음 | 사용자가 생성한 1분 사주 영상에 로고·URL 워터마크(이미 구현됨) + "영상 SNS 업로드 인증 시 포인트 리워드" 이벤트 | 틱톡/릴스/쇼츠에 우리 콘텐츠가 사용자 손으로 유통 |
| V5 | **오늘의 운세 데일리 공유** | 전 5사 데일리 콘텐츠 | 오늘의 운세 페이지(P1-2)에 날짜 박힌 공유 카드 — "오늘 자 운세"는 유통기한이 있어 공유 심리 자극 | 매일 반복되는 소규모 바이럴 |
| V6 | **친구 추천인 리워드** | 업계 표준 | 추천 코드 가입 시 양측 +1,000P (기존 credits 인프라 재활용, IDOR 방지 기존 패턴) | 직접 추천 인센티브 |
| V7 | **유명인 사주 콘텐츠(SEO)** | 청월당 4,110페이지가 검색 유입 자산 | 시사 인물·연예인 명식 해설 페이지(주 1~2건, 관리자 발행) — 검색 유입 → 무료 테스트 → 가입 | 검색 기반 무료 트래픽 |

| **플러스 패스** | 월 9,900P | 라이트 전체 + 추가질문 10% 할인 + 월 1회 기본질문 무료(1,000P 상당) + 월 1회 부적 발행(P1-4 연계) | 헬로우봇 페이백 포지션 — 라이트 이용자의 소비 확대 |

- **갱신 방식**: 가입 시 "매월 포인트 자동차감" 동의 → 잔액에서 차감, 잔액 부족 시 갱신 중지+충전 유도 푸시. 카드 자동결제가 아니므로 **빌링키·구독계약 불필요**, 환불 규정도 기존 포인트 정책 그대로
- **기존 연간회원(12만원/1,000회)과 포지션 분리**: 연간회원=헤비(질문 무제한급), 월 패스=라이트(혜택·습관). 충돌 없음
- **구현**: `settings_service`에 패스 가격·혜택 토글 추가 + `effective_level`/`is_ads_hidden` 연계 + 스케줄러 월 차감 잡 — 기존 패턴 재활용, 난이도 중(3~4일)
