실제로 성립한 것만** 골라 답변의 뼈대로 사용합니다 (합·충·형·파·극 성립 여부는 프로그램이
계산하므로 지어내는 일이 없습니다).

**→ 이 이해가 맞는지 확인 부탁드립니다.**

### 검토 요청사항 (선생님께)
1. 각 공식의 ○/× 와 수정 문구
2. "새로 시작하는 것은 **극**이 우선, 하던 것은 **합**이 우선" 원칙의 적용 범위
   (현재는 미반영 — 다음 단계에서 신규/기존 구분 질문과 함께 반영 예정)
3. 명리전 1권의 "X가 Y를 만나면" 조합 해석도 공식으로 넣을지 여부
   (책 복원이 끝나면 자동 추출 → 같은 방식으로 감수 시트를 드립니다)
4. 계약 공식의 "일지와 剋이 되지 않아야" 조건 — 일지 기준 충·극 판정은
   다음 단계에서 추가 예정(현재는 인수·재 깨짐으로 근사)
